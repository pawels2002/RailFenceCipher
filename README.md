# RailFenceCipher
A simple Java web application for encrypting and decrypting text using the Rail Fence Cipher. This project was created as a university assignment and demonstrates basic web development and classical encryption techniques.
## Features
- Encrypt and decrypt text messages 
- Adjustable number of rails (keys)
- View history of operations
## How it works
The Rail Fence Cipher is a classical transposition cipher. It writes the message in a zigzag pattern across multiple “rails” and then reads it row by row.
### Example
- Text: HelloWorld
- Rails: 3
- Encrypted text: HolelWrdlo
